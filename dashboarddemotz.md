# ТЗ: Демо-сайт с дашбордами

## Цель
Создать демонстрационный веб-сайт с несколькими интерактивными дашбордами для показа возможностей аналитики. Все данные — mock (сгенерированные, без бэкенда).

## Стек
- **Framework:** React + Vite
- **Стили:** Tailwind CSS
- **Графики:** Recharts
- **Иконки:** lucide-react
- **Роутинг:** react-router-dom
- **Данные:** локальные mock-данные (JSON/JS-объекты), без сервера

## Структура сайта

### 1. Layout (общий каркас)
- Боковое меню (sidebar) с навигацией по разделам
- Верхняя шапка: название проекта, переключатель темы (light/dark), профиль-заглушка
- Адаптивность: sidebar сворачивается на мобильных

### 2. Страницы

#### `/` — Обзор (Overview)
- 4 KPI-карточки сверху (выручка, пользователи, заказы, конверсия) — значение + дельта в %
- Линейный график динамики выручки за 12 месяцев
- Круговая диаграмма распределения по категориям
- Таблица последних транзакций (5–10 строк)

#### `/sales` — Продажи
- Столбчатый график продаж по месяцам
- Сравнение план/факт
- Топ-5 товаров (горизонтальный bar-chart)
- Фильтр по периоду (селект: месяц/квартал/год) — влияет на данные

#### `/users` — Пользователи
- График роста пользователей (area chart)
- Разбивка по источникам трафика (pie/donut)
- Карта активности или heatmap-заглушка
- Таблица пользователей с поиском и сортировкой

#### `/analytics` — Аналитика
- Мультилинейный график (2–3 метрики)
- Воронка конверсии (funnel)
- Метрики в виде прогресс-баров

## Общие требования
- Все графики интерактивны (tooltip при наведении)
- Плавные анимации появления карточек
- Единая цветовая палитра (акцентный цвет + нейтральные)
- Тёмная и светлая темы
- Чистая компонентная структура: `components/`, `pages/`, `data/`, `layout/`

## Mock-данные
Создать файл `src/data/mockData.js` с массивами для:
- месячной выручки
- категорий
- транзакций
- пользователей
- источников трафика
- воронки конверсии

## Что НЕ входит
- Реальный бэкенд, БД, авторизация
- Экспорт данных, интеграции с API
- Реальная бизнес-логика — только визуализация

## Критерий готовности
Сайт запускается локально (`npm run dev`), все 4 страницы открываются, графики отображают mock-данные, работает переключение темы и навигация.
